# 🎮 Tic-Tac-Toe Game

A simple and interactive **Tic-Tac-Toe game** built using **HTML, CSS, and JavaScript**.

The game allows two players to play against each other, automatically detects winners, highlights the winning combination, and detects draws.

## 🎯 How to Play

1. Player **O** starts the game.
2. Players take turns clicking an empty box.
3. Player O places `O`.
4. Player X places `X`.
5. The first player to get three symbols in a row wins.

A player can win by getting three symbols:

* Horizontally
* Vertically
* Diagonally

If all nine boxes are filled and nobody wins, the game ends in a **draw**.

## 🏆 Winning Patterns

There are 8 possible winning combinations:

```text
[0, 1, 2]
[3, 4, 5]
[6, 7, 8]

[0, 3, 6]
[1, 4, 7]
[2, 5, 8]

[0, 4, 8]
[2, 4, 6]
```
